# 3–4 minute judge demo

1. **0:00–0:30** Open `/`. Explain the mission and point to five open requests, three resource meters, and two available volunteers.
2. **0:30–1:00** Open `/requests`. Show five fictional intake cases. Open `/resources` to point out the eight-box food reserve, then `/volunteers` to show Ahmed and Sara available while Hassan is not.
3. **1:00–2:10** Return to `/` and click **Run Agent**. With an OpenRouter key configured, wait for the summary. Explain that Strands selected operational tools and the API recorded each result. Open `/activity` to show the resulting timeline.
4. **2:10–2:40** Open the request lacking a location. It should show **Needs Information** and no allocation. Explain that the agent did not invent an address.
5. **2:40–3:20** Open the ten-box event request. It should show **Human Review** because the allocation reaches or crosses protected stock. Enter `4` and click **Reduce allocation**. Show the saved human decision and new reservation in the request timeline.
6. **3:20–3:45** Return to `/` for updated counts. Close with: “NeighborOps automates routine coordination while leaving high-impact decisions with humans.”

If the free model is unavailable, show the explicit error and unchanged operational data. Do not claim the agent completed requests.
